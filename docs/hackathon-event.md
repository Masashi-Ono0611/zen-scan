## About the Workshop

Telegram is becoming one of the most powerful distribution layers in Web3, and TON is where MiniApps, payments, and real users meet.

In this TON x AWS workshop, developers will learn how to design, build, deploy, and scale Telegram MiniApps using AWS serverless infrastructure and agentic AI, all while maintaining performance, cost efficiency, and production-ready architecture.

This is a hands-on, deep-dive workshop, not a demo. Over 72 hours, you'll go from concept to deployed Mini App, leveraging AI-assisted development and modern serverless tooling.

---

## What You'll Learn

### Developing Telegram MiniApps on AWS Serverless Infrastructure with AWS Agentic AI

During the workshop, we'll cover:

### Deploying Telegram Mini Apps on AWS serverless infrastructure
Learn how to design and deploy scalable Mini Apps using AWS-native services.

### Integrating agentic AI into Telegram Mini Apps with Amazon Bedrock
Add intelligent, autonomous AI agents directly into your Mini App workflows.

### Vibe- and spec-based development using Kiro
Build faster with AI-assisted development while maintaining strong specs and structure.

### React Router v7 framework mode on AWS
Implement modern routing and frontends using AWS Lambda, Amazon S3, and Amazon CloudFront.

### Understanding infrastructure & cost efficiency
Learn the real costs of running Telegram Mini Apps and Telegram bots on AWS serverless, and how to optimize them from day one.
